# Design Context

Before UI, UX, or design-system changes, read these project context files:

- `docs/PRODUCT.md` for product strategy, users, register, anti-references, and accessibility expectations.
- `docs/DESIGN.md` for the visual system, palette, typography, component rules, and design guardrails.

ShortHop is a personally operated, client-facing short-link tool. It should feel precise, quiet, and tactile: a client link ledger, not generic SaaS, terminal cosplay, or a busy analytics suite.

Use `APP_URL`-derived domain text for reusable public surfaces. Do not hardcode deployment-specific domains in templates intended for open-source use.
